# Job Tracker

Applicazione web sviluppata con React e Vite per tenere traccia delle candidature lavorative e organizzare la propria ricerca di lavoro.

## Descrizione

Job Tracker è un progetto personale nato per mettere in pratica le competenze acquisite nello sviluppo frontend, lavorando alla realizzazione di un'interfaccia semplice e intuitiva per gestire le candidature.

Il progetto è attualmente in fase di sviluppo.

## Tecnologie utilizzate

- React
- JavaScript
- HTML5
- CSS3
- Vite

## Funzionalità

- Inserimento dei dati delle candidature, tra cui azienda e posizione lavorativa.

## Installazione e avvio

Clona il repository e installa le dipendenze:

```bash
npm install
```

Avvia il server di sviluppo:

```bash
npm run dev
```

Apri nel browser l'indirizzo locale indicato da Vite.

## Obiettivi del progetto

- Consolidare le competenze in React e JavaScript.
- Approfondire la gestione dello stato e degli eventi.
- Sviluppare funzionalità per organizzare e monitorare le candidature.
- Migliorare l'esperienza utente attraverso un'interfaccia chiara e intuitiva.
